# Rain OS Provenance and Legal Checklist

Rain OS is a new project inspired by public behavior and documentation from EndeavourOS, CachyOS, and Athena OS. Before implementation:

- Perform a license review for every reused script, package recipe, patch, icon, font, and documentation fragment.
- Do not reuse project names, logos, screenshots, or trademarks without permission.
- Attribute reused open-source code according to its license.
- Keep Rain OS branding original; the umbrella SVG in this repository is a starting asset, not trademark clearance.
- Publish source and license notices in packages.
- Review distribution of proprietary firmware and fonts separately.
- Create a security disclosure policy and contact address.
- Obtain a domain and trademark review for “Rain OS” before public release.

This document is a project checklist, not legal advice.
