# Lesson 1: Welcome to Rain OS

Welcome to Rain OS! This system provides a clean, resilient Arch Linux experience designed for learning, safety, and productivity.

## Core Architectural Promises
1. **Easy to Learn**: Plain-English tools and guided walk-throughs without intimidating jargon.
2. **Safe to Recover**: Rolling-release velocity paired with dual kernels (latest + LTS fallback) and automated Btrfs snapshot hooks.
3. **Honest Compatibility**: Clear, isolation-aware bridges for Windows applications and games without false promises.
4. **Zero Forced Telemetry**: Privacy by default. Your machine state stays on your device.

## Guided Practice: Inspecting Your System Baseline
Open your terminal (or press Super/Meta and launch **Rain First-Run**) and run:
```bash
rain-first-run
```
This inspects your CPU, GPU, memory, firewall status, and kernel version in real time.

## Where to Get Help
- Run `rain-guide list` anytime in the terminal for offline lessons.
- Launch **Rain Control Center** from your application launcher for system management.
- Offline manuals and configuration files are located under `/opt/rain/`.
