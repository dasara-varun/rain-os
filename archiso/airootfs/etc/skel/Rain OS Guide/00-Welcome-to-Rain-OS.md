# Welcome to Rain OS Guide

Welcome! Rain OS is built with the principle of **Shelter from complexity, without hiding the system.**

## Quick Commands
- `rain-guide list`: List all offline lessons
- `rain-guide read 01`: Start Lesson 1
- `rain-control-center`: Open graphical settings
- `rain-profile list`: View performance profiles
- `rain-hardware-report`: Inspect drivers and GPUs
- `rain-recovery status`: System health report
