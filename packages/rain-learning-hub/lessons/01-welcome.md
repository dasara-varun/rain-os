# Lesson 1: Welcome to Rain OS

Welcome to Rain OS! This lesson helps you understand what makes Rain OS different.

## The Three Promises
1. **Easy to Learn**: You do not need to memorize terminal commands or read external wikis just to use your desktop.
2. **Safe to Recover**: Rolling release operating systems can sometimes encounter issues. Rain OS keeps an LTS fallback kernel ready at all times.
3. **Fast when Hardware Supports It**: Performance profiles are opt-in and reversible.

## Checking Your Environment
Open your terminal and run:
```bash
rain-first-run
```
This displays your current CPU, GPU, memory, and baseline security status.
